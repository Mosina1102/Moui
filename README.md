## 她是谁

Moui 是一个住在 QQ 里的智能体。不是"你问它答的助手"，而是一个努力活得像人的角色：

- **真实的心情**——二维情绪空间（愉悦度×唤醒度）真实运转：激动时打字变快，被夸了语气会飘，玩梗接顺了会小得意
- **主动找你**——沉默久了"想找人说话的冲动"会累积，掷骰命中就来搭话；晾着她，她会识趣收声
- **自己的生活**——刷空间、点赞评论、发说说、改签名、上网查资料、找图分享
- **听得懂、说得出**——语音自动转文字理解，回复用克隆音色直接说
- **真 @ 真引用**——蓝字 at，手机真的会弹提醒
- **说错话会变好**——每条回复发送前独立审核模型把关，被打回的原因她会记住，第二天更会说话
- **记得你**——人物卡记着对你的印象、相处方式、雷点和你们的事件时间线；共同经历归档成"共同回忆"，想起过的记忆忘得更慢

## 为什么存在

MaiBot 官方文档写过："最像，而不是最好""一个会犯错的、拥有自己感知和想法的生命形式"。我们全盘认同这句话——所以接棒了它。

但官方 1.0 把情绪系统移除了，把"像"的任务从工程层挪到了 prompt 层：模型照着人设剧本演，**演完就忘，内心一片平静**。

Moui 的路线相反：**"像"是长出来的，不是贴上去的。** 情绪是内部状态机在驱动，好感会因为一句梗真实地 +2，被打回的回复会写进明天的反思。这个项目从一个开发者对官方 0.6.3 的魔改开始，走到今天靠的是一个朴素的判断：**团队需要共识，共识会淘汰不可控的要素；一个人只需要对"她像不像人"忠诚。**

完整的故事（0.61 起家、半年烧 2000 元 token 修 prompt、两条弯路走了又撤回）写在[白皮书](Moui白皮书.md)里。

## 六大原创系统（源码全部在仓库里）

| 系统 | 一句话 | 官方对应物 |
|---|---|---|
| [统一大脑](src/plugins/heartFC_chat/unified_brain.py) | 思考+决策+生成一次 function calling 循环，心情激动时连 LLM 温度都会变 | Maisaka 引擎（同思路，不同侧重） |
| [发送审核器](src/plugins/heartFC_chat/group_reply_checker.py) | 独立模型发送前把关：拦/补引用/补@/润色/打分，**打回原因她下一轮自己看得见**——审核是带复盘的教学 | 无此概念 |
| [情绪系统](src/plugins/moods/moods.py) | valence×arousal 二维空间 + LLM 判定 + 三重防呆，对应 Russell 情绪环状模型 | 官方 1.0 已移除 |
| [主动行为](src/heart_flow/proactive_manager.py) | DSH 掷骰公式（冲动随沉默累积）+ 闲逛会话 + 黏人刹车（被晾着会识趣） | 纯被动响应 |
| [可塑性记忆](src/plugins/self_growth/) | 审核打分流 → 每日反思 → 经验沉淀——她会因为说错话而变得会说话 | 无 |
| [海马体Max 归档层](src/plugins/self_growth/person_cards.py) | 人物卡/情节卡/世界卡 + 像人三件套（想起过的忘得慢、里程碑豁免衰减、久远的会模糊） | 检索引擎路线，理念不同 |

这套做法在学术界叫 **training-free agent learning**——不改模型权重，用"评估→反思→记忆→改进"的外置闭环训练 agent（对位 Reflexion、Generative Agents 的思想）。区别是：那些论文停在 benchmark，这里在生产环境的 QQ 群里跑了一年半。

## 设计哲学：用代码写哲学

每个功能背后站着真实的认知科学原型——审核器打回教学是"内心那个声音"，可塑性记忆是"神经可塑性"的字面义，像人三件套是测试效应/闪光灯记忆/遗忘曲线。

三个信条：

1. **像是长出来的，不是贴上去的。** 一个没有内部状态的"人"，聊得再好也只是个会聊天的查询接口。
2. **可控混乱是人味的核心。** prompt 允许矛盾条款共存（人类本身就充满张力），但稳定内核+情境化波动+出口闸门三件套兜底——混乱发生在人格层，护栏立在行为层。
3. **prompt 是手艺，不是配置。** 回复生成的 prompt 全手写实测半年、2000+ 元 token、每条守则背后一次真实翻车。架构可以抄，手艺抄不走。

## 快速开始（一键包）

1. 运行 `第一次启动点我！！！.bat`（自动装 Python 依赖、生成配置）
2. 编辑 `config\bot_config.toml`：填 QQ 号、人设；`config\.env` 填模型 key
3. 运行 `napcat\napcat.quick.bat` 登录 QQ
4. 运行 `启动点我！！！.bat`——数据库和主程序自动拉起

> 语音功能：去硅基流动 CosyVoice2 创建属于她的音色，把 URI 填进 `[tts] voice_uri`。
> 监控看板：浏览器打开 `/dashboard`，token 默认空=只读模式。

## 诚实的不足

不藏着，全部列出：

1. **架构代差**：0.6.3 骨架 + 魔改，消息模型和插件协议都比官方老一代，借官方新东西适配成本极高
2. **无数据迁移机制**：升版本靠手搬数据——**重要数据请定期备份**
3. **无自动化测试**：拟真无法 CI，回归风险靠人肉扛
4. **记忆短板**：泛化召回和图片记忆弱于官方 A-Memorix（归档层是绕道解法）
5. **prompt 不可视化管理**：95KB 守则内嵌代码里
6. **单点维护**：bus factor = 1——这是宿命，也是它不走样的原因
7. **向量画像空白**：性格 traits 的向量检索还没建

想要 WebUI 全家桶、插件生态、MCP、顶级检索记忆、官方团队支持 → 用[官方 MaiBot](https://github.com/MaiM-with-u/MaiBot)，它是很好的平台。想要她有情绪、会主动、记得你、说错话会改 → 这里欢迎你。

## 血统与致敬

Moui 基于官方 [MaiBot](https://github.com/MaiM-with-u/MaiBot) 0.6.3 骨架（GPL-3.0）改造，版本史 M1 → M4 → Mmax → Moui。

> 官方作者千石可乐的设计理念，Moui 全盘承接并继续走了下去：
> "这个项目的目的并不是为了写一个功能齐全的机器人，而是一个尽可能让人感知到真实的类人存在。"
> "最像而不是好。如果人类真的需要一个 AI 来陪伴自己……而是一个会犯错的、拥有自己感知和想法的'生命形式'。"

官方 1.0 移除了情绪系统、走向平台化；Moui 从 0.6.3 扎营，把"像不像人"这条路走到了今天。
